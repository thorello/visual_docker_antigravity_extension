# Capacidades da IA (Skills)

Este arquivo lista os comandos e ferramentas que a IA pode utilizar para gerenciar este projeto.

## Comandos do VS Code Extension
- `npm run compile`: Compila o código TypeScript.
- `npm run watch`: Inicia a compilação em tempo real.
- `npm run package`: Gera o arquivo `.vsix` para distribuição.
- `npm run lint`: Executa a verificação de estilo do código.

## Comandos de Validação
- `scenarios/run-tests.js`: (Em desenvolvimento) Scripts para validar o estado da Webview ou lógica de árvore.
