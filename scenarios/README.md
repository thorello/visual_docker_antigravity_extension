# Antigravity Extension Scenarios

Este diretório contém scripts de teste e validação para a extensão Antigravity.

## Estrutura
- `/results`: Armazena os logs e resultados das execuções.

## Como Executar
Todos os cenários podem ser executados via Node.js:
`node scenarios/<nome-do-cenario>.js`
